## 2024-05-24 - React Component Memoization and Referential Equality for Streaming Interfaces
**Learning:** In highly dynamic React interfaces like streaming chat, wrapping complex list item components (such as `MessageBubble` child components `TraceAccordion`, `SupervisorRail`, etc.) in `React.memo` is only effective if their props preserve referential equality. Using inline fallbacks (e.g., `prop || []`) on every render will cause `React.memo` checks to fail, leading to heavy, unnecessary re-renders.
**Action:** Always extract fallback arrays or objects as stable constants outside the component (e.g., `const EMPTY_ARRAY: never[] = [];`) when passing them as props to memoized child components, and ensure functions passed as props to custom components are wrapped in `React.useCallback`.
