## 2024-06-15 - [LLM UI Token Streaming Performance]
**Learning:** In streaming chat interfaces like `MessageBubble.tsx`, complex child UI components (such as `SupervisorRail` or `ArtifactBadgeRow`) will needlessly re-render on every token update if they are not wrapped in `React.memo` and if their parent passes down unstable references (like inline arrays `|| []` or inline arrow functions for handlers). This causes a significant performance bottleneck due to React's referential equality checks failing on every single keystroke.
**Action:** When building complex streaming chat interfaces, extract fallback arrays to global stable constants (e.g., `const EMPTY_ARRAY: never[] = [];`), wrap interactive event handlers passed to children in `useCallback`, and wrap the heavy child components themselves in `React.memo()`. Also, never commit temporary `.mjs` scripts used for multi-line replacements.
